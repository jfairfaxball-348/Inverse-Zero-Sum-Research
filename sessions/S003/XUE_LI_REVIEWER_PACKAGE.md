## Proposal summary

For
`G_m=C_2 \oplus C_{2m} \oplus C_{2m}`, Girard--Schmid (JNT 2019)
prove `s(G_m)=8m+1`. The proposed inverse problem is to classify every
length-`8m` sequence with no zero-sum subsequence of length
`exp(G_m)=2m`, for all `m>=2`.

Girard--Schmid's Acta Math. Hung. 2020 inverse theorem instead classifies the
different family `C_2 \oplus C_2 \oplus C_{2n}`, and the common endpoint
`m=1` is the already understood `C_2^3` case. A bounded 2026-10-02 audit
searched later papers, recent preprints, theses, forward citations and
alternate notation. It found active inverse work on the same ambient rank-three
families for other invariants such as `disc(G)`, but no source completing the
displayed ordinary-EGZ classification and no source explicitly certifying it
open. The project therefore treats current openness/novelty as unverified.
