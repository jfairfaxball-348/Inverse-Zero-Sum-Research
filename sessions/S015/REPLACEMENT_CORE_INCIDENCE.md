# S015 — ambient replacement-core incidence

Date: 2026-10-04. Classification: internal programme mathematics, using only
the S014 ambient replacement theorem and the published threshold already
rechecked there. No independent review, formalisation or novelty certification.

## 1. Domain and inherited theorem

Put
\[
G=G_m=C_2\oplus C_{2m}\oplus C_{2m},\qquad n=2m,\qquad m\ge 2.
\]
Let `S` be a CAND-02 extremal:
\[
|S|=4n,\qquad 0\notin\Sigma_n(S).
\]

For every `x in G`, S014 defines
\[
\mathcal R_x(S)=\{A\mid S:|A|=n-1, \sigma(A)=-x\},
\qquad
K_x(S)=\bigcap_{A\in\mathcal R_x(S)}\operatorname{pos}(A).
\]
S014-P1 gives `R_x(S) != empty`; S014-P3 gives
\[
S_{p\to x}\text{ extremal}\iff p\in K_x(S),
\]
and `|K_x(S)|<=n-1`. For a support value `a`, S014-P2 gives
`P_a subseteq K_a(S)`, where `P_a` is the set of old `a`-positions.

S015 stays entirely in this ambient system. No quotient, kernel pair-sum,
capacity, local-hole or progressive-block input is used below.

## 2. S015-P1 — exact core transport and value-class saturation

**PROGRAMME THEOREM; PROVED.** Let `p` be an old position of value `b`
and suppose `p in K_x(S)`. Let `x_*` be the new position in
\[
S'=S_{p\to x}=Sp^{-1}x_*.
\]
Then `S'` is extremal and replacement induces a bijection
\[
\Phi:\mathcal R_x(S)\longrightarrow\mathcal R_b(S'),
\qquad
A\longmapsto Ap^{-1}x_*.
\]
Moreover,
\[
K_b(S')=(K_x(S)\setminus\{p\})\cup\{x_*\}.       \tag{S015.1}
\]

Consequently, if one position of a support value `b` lies in `K_x(S)`,
then **every** old `b`-position lies in `K_x(S)`. Thus every ambient core
is a union of complete value classes:
\[
K_x(S)=\bigsqcup_{b\in I_x(S)}P_b
\]
for a subset `I_x(S) subseteq supp(S)` (possibly empty).

**Proof.** Since `p in K_x(S)`, every `A in R_x(S)` contains `p`.
Replacing `p` by `x_*` changes the sum from `-x` to
`-x-b+x=-b`, so `Phi(A) in R_b(S')`.

Conversely, replacing `x_*` by `b` recovers a sequence equal to `S`,
hence extremal. Applying S014-P3 inside `S'` shows
`x_* in K_b(S')`; therefore every `B in R_b(S')` contains `x_*`.
Replacing `x_*` by the old position `p` sends `B` back to a member of
`R_x(S)`. This is the inverse map, and intersections give (S015.1).

Now let `q!=p` be another old `b`-position. It is still a `b`-position
of `S'`. S014-P2 applied to support value `b` in `S'` gives
`q in K_b(S')`, hence (S015.1) gives `q in K_x(S)`. If `p` was the
only `b`-position, the conclusion is already tautological. QED.

**Interpretation.** Safe replacement depends on the value class being deleted,
not on which occurrence is chosen. This is a simultaneous ambient conclusion,
not an isolated formal one-change pair.

### Augmented-core invariant

Write `C_x(S)` for the value-sequence occupying the positions `K_x(S)`,
and define the formal augmented core
\[
\widehat C_x(S)=C_x(S)\,x_*.
\]
Under the safe replacement above,
\[
\widehat C_b(S')=\widehat C_x(S)
\]
as value-sequences: the move merely swaps the external target token `x`
with the chosen core value `b`. Thus core size and the augmented multiset are
invariant along the exchange generated by (S015.1).

## 3. S015-P2 — support-incidence weights and exact deficit descent

For support values `a,b`, write
\[
b\rightsquigarrow a
\quad\Longleftrightarrow\quad
P_b\subseteq K_a(S).
\]
By S015-P1 this is equivalent to one, hence every, old `b`-position being
safely replaceable by `a`.  The relation is reflexive.

**PROGRAMME COROLLARY; PROVED.** Suppose `b!=a` and
`b \rightsquigarrow a`. Put
\[
r=v_a(S),\qquad s=v_b(S),\qquad d_a=n-r-1.
\]
Then
\[
r+s\le |K_a(S)|\le n-1,                            \tag{S015.2}
\]
\[
r\le n-4,\qquad s\le n-3.                         \tag{S015.3}
\]

In particular:

- multiplicity `n-2` remains impossible by S014;
- multiplicity `n-1` is isolated by S014;
- **multiplicity `n-3` is also isolated:** if `v_a(S)=n-3`, then
  `K_a(S)=P_a`;
- for `m=2` (so `n=4`), every support core is isolated:
  `K_a(S)=P_a`.

Moreover every nontrivial incidence gives an exact one-step deficit descent.
For every `p in P_b`,
\[
0\in
\Sigma_{d_a-1}\bigl((-a)+(Sa^{-r}p^{-1})\bigr).   \tag{S015.4}
\]
S014 already gives a translated zero sum of exact length `d_a` in
`(-a)+(Sa^{-r})`; a safe source class therefore forces the shorter exact
length `d_a-1` after deleting **each** source position.

**Proof.** Equation (S015.2) follows because both complete value classes
`P_a` and `P_b` lie in `K_a`.

Choose `p in P_b` and form `S'=S_{p->a}`, which is extremal. Its
`a`-multiplicity is `r+1`. If `r=n-3`, then `S'` would have the
forbidden multiplicity `n-2`, contradicting S014-P4. The original sequence
already excludes `r=n-2`, and `r=n-1` would give `K_a=P_a` by S014-P4,
contrary to the nontrivial incidence. Hence `r<=n-4`.

Likewise the `b`-multiplicity in `S'` is `s-1`. The original sequence
excludes `s=n-2`; if `s=n-1`, then `S'` would have forbidden
`b`-multiplicity `n-2`. Hence `s<=n-3`.

Finally, in `S'` the support value `a` has multiplicity `r+1<=n-3`.
Applying S014-P4 to `a` in `S'` gives a translated support-deleted zero
sum of exact length
`n-(r+1)-1=d_a-1`. Deleting all `a`-positions of `S'` removes the
new `a` replacing `p` together with the old `a`-positions, leaving
exactly `Sa^{-r}p^{-1}`. This proves (S015.4). QED.

For the first unresolved high target stratum `r=n-4`, (S015.4) says that
after deleting any safely replaceable source position, the support-deleted
sequence contains a non-`a` pair summing to `2a`.

## 4. S015-P3 — the ambient two-extension witness contains the transported core

**PROGRAMME THEOREM; PROVED.** Let `p in K_x(S)` have value `b`, and
put `T=Sp^{-1}`. Then
\[
\mathcal Q_{p;x,b}
=
\{C\mid T:|C|=n-2, \sigma(C)=-(x+b)\}
\]
is nonempty. More strongly, every `C in Q_{p;x,b}` contains all positions
of `K_x(S)\setminus\{p\}):
\[
K_x(S)\setminus\{p\}
\subseteq
\bigcap_{C\in\mathcal Q_{p;x,b}}\operatorname{pos}(C).  \tag{S015.5}
\]

**Proof.** Both `Tb_*` (a positional relabelling of `S`) and
`Tx_*=S_{p->x}` are extremal and have length `4n`. The sequence
`Tx_*b_*` has length `4n+1=s(G)`, so the published threshold forces an
`n`-term zero sum. It cannot omit `x_*`, since then it lies in the
extremal `Tb_*`; it cannot omit `b_*`, since then it lies in the extremal
`Tx_*`. Removing both new positions yields a member of `Q_{p;x,b}`.

For any `C in Q_{p;x,b}`, the sequence `Cx_*` has length `n-1` and
sum `-b`, hence belongs to `R_b(Tx_*)`. S015-P1 gives
\[
K_b(Tx_*)=(K_x(S)\setminus\{p\})\cup\{x_*\}.
\]
Therefore `Cx_*` contains this transported core, and `C` contains
`K_x(S)\setminus\{p\}`. QED.

This witness is an original-group consequence of applying the same exact
threshold to the common deletion star `T`. It is not the S009
`C_m^2` one-change witness.

## 5. S015-P4 — exact core factorization and the first near-full strata

Let `C_x` denote the positional subsequence of `S` occupying `K_x(S)`,
put
\[
k_x=|K_x(S)|,\qquad \delta_x=n-1-k_x,
\]
and define the residual representation family
\[
\mathcal F_x=
\{D\mid SC_x^{-1}: |D|=\delta_x,\sigma(D)=-x-\sigma(C_x)\}.
\]

**PROGRAMME LEMMA; PROVED.**

1. `F_x` is nonempty and every member of `R_x(S)` is uniquely
   `C_xD` with `D in F_x`.
2. If `delta_x>0`, then the positional intersection of all members of
   `F_x` is empty.
3. If `delta_x=0`, then `R_x(S)={C_x}`: the representation is unique.
4. If `delta_x=1`, there is a support value
   [
   c_x=-x-\sigma(C_x)
   ]
   with at least two occurrences, all outside `K_x(S)`, and
   `F_x` is exactly the family of singleton positions carrying value
   `c_x`.

**Proof.** By definition every representation contains `K_x`; stripping
those fixed positions gives (1). If some outside position belonged to every
residual `D`, then it would belong to every member of `R_x` and hence to
`K_x), a contradiction; this proves (2). Item (3) is immediate.

For `delta_x=1`, every residual is one position and its value is forced by
the displayed sum equation, so all residual positions carry the same value
`c_x`. Empty intersection requires at least two such positions. Conversely
every outside occurrence of that value completes `C_x` to a representation.
By S015-P1 a core cannot contain only some occurrences of a value class, so
the existence of outside `c_x`-positions implies that no `c_x`-position
lies in `K_x`. QED.

Thus a near-full core is not an arbitrary positional set. Deficit zero is a
unique representation block; deficit one has a completely determined
equal-valued reservoir outside the core. Deficit two is the first unresolved
case: the residual family is a fixed-sum pair family with empty positional
intersection.

## 6. D14-01 outcome

S015 does **not** prove or disprove the existence of a genuinely nontrivial
support incidence `K_a\setminus P_a != empty` in an actual CAND-02 extremal.
It does meet the brief's second success criterion by proving a global ambient
reconstruction/incidence theorem with classification leverage:

- every core is a weighted union of complete support value classes;
- a safe move transports the entire representation family and core exactly;
- the augmented core is invariant under the resulting exchange;
- nontrivial support incidence is impossible into multiplicity `n-3` or
  `n-1`, while `n-2` is impossible altogether;
- every nontrivial incidence forces exact deficit descent after deleting each
  source occurrence;
- the common deletion star has an exact `n-2` witness containing the whole
  transported core; and
- near-full cores factor into an explicit residual representation system.

No quotient-fiber information was needed, so the route has not collapsed into
the stopped D7--D10 architecture.

The first genuinely unresolved ambient stratum is simultaneous compatibility
of a nontrivial support incidence with a near-full core, especially
`delta_a<=2`. That is a bounded successor question; it is not claimed that
resolving it alone classifies CAND-02.
